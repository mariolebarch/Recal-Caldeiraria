# Recal Estruturas e Caldeiraria · site institucional

Site institucional da **Recal Estruturas e Caldeiraria** (Ipatinga, MG), caldeiraria pesada no Vale do Aço desde 2003.

## Páginas
- `index.html`: página principal (peças fabricadas, clientes, capacidade, serviços, engenharia, orçamento e contato)
- `historia.html`: linha do tempo da empresa
- `equipe.html`: nossa equipe
- `apresentacao.html`: "Recal em 90 segundos", apresentação institucional para tablet e tela cheia
- `politica-privacidade.html` e `termos-de-uso.html`

## Tecnologia
HTML, CSS e JavaScript puros, sem build. Three.js (`vendor/`) roda localmente para o modelo 3D.
O sistema visual (cores, tipografia e componentes) está descrito em [`DESIGN.md`](DESIGN.md).

## Rodar localmente
```bash
python -m http.server 5530
```
Depois abra http://localhost:5530.
